## 零、红线

- 🔴 工具名全部 `mxpage_*` 前缀；不注册 `generate_image` / `image_generate` / `edit_image` —— ✅ 全库核查，工具清一色 `mxpage_*`，不抢占生图插件工具名
- 🔴 密钥只读环境变量 / 设置服务，不出现在浏览器页面、日志、报错信息里 —— ✅ 渠道只存环境变量名，真机扫描页面无密钥明文
- 🔴 失败可读：额度 / 端点 / 模型 / 取消 四类失败给出的文案能区分原因，无堆栈、无密钥 —— ✅ 四类文案实测可区分
- 🔴 不自动改写用户输入的商品描述与提示词 —— ✅ 描述/提示词原样透传
- 🔴 不自动删除任何已生成的图片与项目文件 —— ✅ 无自动清理逻辑，jobs.json 与产物只增不删
- 🔴 文本-only 对话路由不因未声明 image block 而拒绝普通对话 —— ✅ 路由放行普通对话（实测）
- 🔴 面板 / 入口的任何异常不得导致 DSH 主界面白屏或会话消失 —— ✅ 此前的"会话消失"事故已修复（面板异常隔离），真机开关面板会话列表原样保留
